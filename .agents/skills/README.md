# Agent skills

Skills for coding agents that work with Rookery. Each skill is a folder with a
`SKILL.md` that starts with a YAML header (`name`, `description`) and then
has the instructions in Markdown.

| Skill | Use it to |
| --- | --- |
| [`install-rookery`](install-rookery/SKILL.md) | Install the Rookery client, a Rookery server, a node for Incus and Docker machines, or Ubuntu on a server from a rescue system |

`.claude/skills` is a link to this folder, so Claude Code finds the same skills.
