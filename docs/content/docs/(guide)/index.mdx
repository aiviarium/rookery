Rookery sets up Ubuntu 26.04 amd64 machines for coding agents and manages them from your own computer. Each machine, a *host*, gets a desktop you can watch from the browser and the tools around the agents. The agents themselves come from [plugins](/docs/extend/plugins). Rookery's terminal UI has a page per host for status, sign-ins, updates and secrets.

Rookery can also make the machines. A provisioner plugin, such as the Docker or Incus plugin, creates a container or a VM, and Rookery sets it up like any other host ([Provisioners](/docs/deploy/provisioners)).

## On each host

- XFCE on a persistent virtual display, reached in the browser through noVNC
- The agents you choose, installed by [plugins](/docs/extend/plugins)
- Firefox, Chromium, Chrome, LibreOffice, image, PDF and OCR tools
- Development toolchains for Node, Python, Go, Rust, the JVM, .NET and more ([Tools](/docs/reference/tools))
- A desktop adapter for agents, as a command and as an MCP server ([box](/docs/reference/box))
- Tailscale, the Cockpit web console and unattended security updates
- An *operator* account for you and an *agent* account for the coding agents

A laptop also gets a physical XFCE login. Graphics run on the host's GPU or on the CPU ([Graphics](/docs/reference/graphics)). Other software, such as the GitHub CLI, the Unity CLI or nightly backups, comes as plugins too.
